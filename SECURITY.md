# Security and soundness reports

For a potentially exploitable repository issue, use GitHub's private
**Security → Report a vulnerability** channel for
`https://github.com/khanukov/erdos36` when available.  If private reporting is
unavailable, open a minimal issue requesting a private contact channel and do
not disclose exploit details there.

Mathematical counterexamples, interval-arithmetic soundness defects,
certificate mismatches, and false-positive verifier behavior should be
reported as high-priority correctness issues.  Do not describe this
preliminary repository as security-audited or formally verified.
