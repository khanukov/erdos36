# Manuscript

`main.tex` is the source of a preliminary and unrefereed manuscript. Build it
with `make paper`; the PDF is written under the ignored `build/` directory.
Create the minimal deterministic arXiv source archive with `make arxiv`.

The manuscript is CC BY 4.0. It records Zenodo concept DOI
`10.5281/zenodo.21969298`; historical `v0.1.0-preprint` has version DOI
`10.5281/zenodo.21969299`. No version DOI is asserted for
`v0.1.1-preprint` until Zenodo assigns it. No statement in the manuscript is
Lean-verified.
